# FM 音源（Z-MUSIC ver2）

[← 使い方（MANUAL）へ](../MANUAL.md)

FM 音源の曲（BGM）と効果音を、Z-MUSIC ver2 で鳴らせます。曲と効果音は、Z-MUSIC の **MML**（音楽を文字で書いたテキストファイル。拡張子 `.zms`）で書きます。
MML のファイルを mkanim・mkscene に指定するだけで、ツールが MML を Z-MUSIC のデータに変換して .pan の中に入れ、決めた時刻に鳴らす命令も .pan に入れます。

## 1. 全体の流れ

1. **MML を書く**：テキストエディタ（メモ帳、VS Code など）で `.zms` のファイルを作ります（書き方は 3 章）。
   置く場所は自由ですが、mkscene の設定ファイルと同じフォルダに置くと、ファイル名だけで指定できて楽です。
2. **MML を指定する**：
   - mkanim：`--fm 曲.zms`（4 章）
   - mkscene：設定ファイルに `fm = "曲.zms"`、効果音は `[[se]]` の `src = "効果音.zms"`（5 章）
3. **ツールを動かす**：MML は自動で変換されます（Z-MUSIC 本体の ZMUSIC.X で、MML を Z-MUSIC のデータ「ZMD」にコンパイルする）。
   MML に間違いがあれば、ここで「ファイル名 行目：内容」のエラーで止まります。
   変換したデータ（`fm.zmd` など）は出力先のフォルダにも残り、.pan の中に入ります。**MML を直したら、ツールをもう一度動かします。**
4. **X68000（実機・エミュレータ）で再生する**：先に Z-MUSIC を常駐させてから panic で再生します（2 章）。
   ```
   zmusic\zmsc -n -t0 -w0
   panic anim\fmdemo\fmdemo.pan
   ```

まず試すなら、付属のサンプル（`setup.bat --samples` で絵の素材を作ってから）：

```
pt mkscene samples\fm\fm.toml
```

`x68\anim\fmdemo\fmdemo.pan` ができます。曲が鳴り続け、2 秒ごとに効果音が鳴り、キーで終わります。
MML は `samples\fm\bgm.zms`（曲）と `samples\fm\se.zms`（効果音）、設定は `samples\fm\fm.toml` です。自分の MML を書くときの手本にしてください。

## 2. 準備と再生

- setup.bat が、Z-MUSIC ver2.08 を `x68/zmusic/` に、マニュアルを `docs/zmusic/` に置きます（どちらも retropc.net から。転載可）。

  | ファイル              | 使い道                                                                             |
  | --------------------- | ---------------------------------------------------------------------------------- |
  | `x68/zmusic/zmsc.x`   | 再生専用の Z-MUSIC（常駐が小さい）。X68000 で panic より先に常駐させる             |
  | `x68/zmusic/zmusic.x` | Z-MUSIC 本体。PC 側では MML のコンパイル（`zmusic -c`）に使う（run68 で動かす）    |
  | `x68/zmusic/zp.r`     | プレイヤー。`zp -s` で演奏を止める                                                 |
  | `docs/zmusic/ZM*.MAN` | マニュアル（Shift-JIS）。MML は ZM5.MAN、ZMS コマンドは ZM4.MAN、効果音は ZM14.MAN |

- **再生する前に、X68000 で Z-MUSIC を常駐させます。** 例（`x68/` を H: として共有しているとき。H:\ で）：
  ```
  zmusic\zmsc -n -t0 -w0
  panic anim\fmdemo\fmdemo.pan
  ```
  - `-n`（初期化なし）：曲を鳴らし始めるときの初期化（主に MIDI の機器向け）を省きます。**付けることを勧めます。**
    付けないと、曲を鳴らす命令（ZMPL）が 10MHz で約 0.12 秒かかり、その間は絵が止まります（付けると一瞬）。FM 音源の音は変わりません。
  - `-t0 -w0`：曲のデータは .pan の中に置いたまま鳴らすので、Z-MUSIC のトラックバッファと作業領域は要りません。
  - 常駐は 1 回でかまいません（いくつ .pan を再生しても、そのまま使えます）。ZMUSIC.X を常駐させていてもかまいません。
    常駐を外すときは `zmusic\zmsc -r`。
- 実機で使うときは、`zmsc.x` を .pan と一緒に写します。
- Z-MUSIC が常駐していないときは、FM 音源の命令は何もしません。絵と ADPCM の音は、ふだんどおり再生されます。
- Z-MUSIC ver3 とは互換性がありません（ver3 が常駐しているときも、FM 音源の命令は何もしません）。

## 3. MML の書き方（最小の形）

くわしい書き方は Z-MUSIC のマニュアル（`docs/zmusic/`。MML は ZM5.MAN、`(i)`・`(m…)` などの「ZMS コマンド」は ZM4.MAN）にあります。
ここでは、ツールで使うのに要る形だけを説明します。`/` から行の終わりまではコメントです。

**曲**（`samples/fm/bgm.zms` を短くしたもの）：

```
(i)                         / 1. 初期化（いつも先頭に書く）

(v1,0                       / 2. 音色 1 番の定義（FM 音源のパラメータ。55 個の数）
  7, 15, 0, 0, 0, 0, 0, 0, 0, 3, 0     /    AF OM WF SY SP PMD AMD PMS AMS PAN（最後の 0 は使わない）
 31, 12, 3, 7, 4, 20, 0, 1, 3, 0, 0    /    オペレータ 1：AR DR SR RR SL OL KS ML DT1 DT2 AME
 31, 14, 4, 7, 5, 36, 0, 2, 3, 0, 0    /    オペレータ 2
 31, 16, 5, 7, 6, 44, 0, 4, 3, 0, 0    /    オペレータ 3
 31, 10, 2, 7, 4, 40, 0, 1, 7, 0, 0)   /    オペレータ 4

(m1,2000)(a1,1)             / 3. トラック 1 を 2000 バイト確保し、チャンネル 1（FM1）をトラック 1 に割り当てる
(m2,2000)(a2,2)             /    トラック 2 にチャンネル 2（FM2）

(t1)t130 @1 v12 o5 l8 [do] c e g e f a <c> a [loop]   / 4. トラック 1 の MML（テンポ 130、音色 1、音量 12、…）
(t2)     @1 v13 o3 l4 [do] c c f f [loop]             /    トラック 2 の MML

(p)                         / 5. 演奏開始（Z-MUSIC で直接鳴らすときの命令。ツールでは無視されるので、書いても書かなくてもよい）
```

- `(a チャンネル,トラック)`：チャンネル 1〜8 が FM1〜FM8 です（9 は ADPCM、10〜25 は MIDI）。
- `[do]`〜`[loop]` で囲むと、終わりなくくり返します。くり返さない曲は、最後まで鳴ったら止まります。
- 音色は、自分で定義する（`(v…)`）か、ほかの MML から写します。音色の定義の無い番号は鳴りません。

**効果音**（`samples/fm/se.zms`）：

```
(v3,0                       / 音色 3 番（曲の音色と番号を重ねない）
  7, 15, 0, 0, 0, 0, 0, 0, 0, 3, 0
 31,  8, 6, 9, 6, 10, 0, 4, 0, 0, 0
 31, 10, 6, 9, 6, 30, 0, 8, 3, 0, 0
 31, 12, 6, 9, 6, 50, 0,12, 5, 0, 0
 31, 14, 6, 9, 6, 60, 0, 2, 7, 0, 0)
(m1,500)(a8,1)              / トラック 1 にチャンネル 8（FM8）。効果音は FM8 で鳴る

(t1)@3 v15 q8 o6 l32 b a g f e d c > b a g f e d c    / テンポは書かない
```

- 効果音は「曲のどれかのトラックに割り込ませて」鳴らします。決まりは 6 章にまとめました。この例では、曲が FM8 を使っていないので、曲のトラック 8（空き）に割り込ませます。
- 効果音の MML では `(i)` を省略してかまいません（ツールが変換するときに、MML の頭に `(i)` を足します。`(i)` が無いと音量が 0 で変換されてしまうため）。

**ファイルについて**：

- 文字コードは Shift-JIS でも UTF-8 でもかまいません（ツールが Shift-JIS・CRLF にしてから変換します）。拡張子は `.zms` か `.opm`。
- Z-MUSIC で変換済みの ZMD（`.zmd`）も、MML の代わりに指定できます（そのまま使います）。
- 当時の MML（ゲームの曲など）を使うときは、FM 音源のトラックだけの曲にしてください。Z-MUSIC の ADPCM のトラックは使えません（6 章）。

## 4. mkanim で使う

`--fm 曲のファイル` を足すだけです。ファイルのパスは、**コマンドを実行しているフォルダ（ふつうは panicCreationKit のフォルダ）からの相対**か、絶対パスで書きます。

```
pt mkanim samples\anim2 fmtest --diff --forever --fm samples\fm\bgm.zms
```

- 実行すると、次のような表示が出ます：
  ```
  bgm.zms → fm.zmd（曲、225 バイト、トラック 2 本：FM1 FM2）
  FM 音源の曲：0.00 秒後に鳴らす（最初に 1 回だけ）
  ```
  「トラック 2 本：FM1 FM2」は、曲が使うチャンネルです。思ったチャンネルになっているか確かめてください。
- 出力先（`x68\anim\fmtest\`）に `fm.zmd` が残り、.pan の中にも入ります。
- オプション：

  | オプション       | 意味                                                                                    | 既定 |
  | ---------------- | --------------------------------------------------------------------------------------- | ---- |
  | `--fm ファイル`  | 曲（MML か ZMD）                                                                        | なし |
  | `--fm-offset 秒` | 曲を鳴らし始める時刻（アニメの始まりから。0 以上）                                      | 0    |
  | `--fm-every N`   | 永久ループ（`--forever`）で N 周ごとに、曲を止めて頭から鳴らし直す。0 は最初に 1 回だけ | 0    |

- 永久ループでないときは、アニメが終わると曲も止まります。曲の長さはアニメの長さに合わせてください（曲が短ければ、先に終わって無音になります）。
- 設定ファイル（`--config`）に書くときは、`fm = "bgm.zms"`、`fm_offset = 0.5` のように書きます。
  このときのパスは、**設定ファイルのあるフォルダからの相対**です。
- 効果音は mkanim では鳴らせません。mkscene の `[[se]]` を使ってください（mkanim と同じ 1 枚の絵の層だけの設定でも作れます。5 章の例）。
- `--split` とは一緒に使えません。ADPCM の音（`--audio` や動画の音）と同時に鳴らせます。

## 5. mkscene で使う

設定ファイルに、曲は `fm`（と `fm_offset`・`fm_every`）、効果音は `[[se]]` を書きます。ファイルのパスは、**設定ファイルのあるフォルダからの相対**か、絶対パスです。

例：次のようなフォルダを作った場合です。

```
mywork\
  demo.toml        設定ファイル
  bgm.zms          曲の MML
  shot.zms         効果音の MML（FM8）
  chara\           絵（PNG 連番）
```

`demo.toml`：

```
name = "demo"
loops = 2                 # 1 周＝chara（12 枚・12fps）の 2 ループ＝2 秒
loop = "forever"
diff = true

fm = "bgm.zms"            # 曲：最初に 1 回だけ鳴らす（曲の中の [do]〜[loop] でくり返す）

[[se]]                    # 効果音 1 つ目
src = "shot.zms"
offset = 0.5              # 周の頭から 0.5 秒の所で
every = 1                 # 毎周

[[se]]                    # 効果音 2 つ目（同じ MML を別の時刻にも鳴らせる）
src = "shot.zms"
offset = 1.5
every = 2                 # 2 周に 1 回

[[layer]]
name = "chara"
plane = "g0"
src = "chara"
base = true
fps = 12
```

```
pt mkscene mywork\demo.toml
```

- 実行すると、次のような表示が出ます：
  ```
  bgm.zms → fm.zmd（曲、137 バイト、トラック 2 本：FM1 FM2）
  効果音 se0：shot.zms（トラック 1 本：FM8）を曲のトラック 8 から鳴らす
  効果音 se1：shot.zms（トラック 1 本：FM8）を曲のトラック 8 から鳴らす
  FM 音源の曲：0.00 秒後に鳴らす（最初に 1 回だけ）
  効果音 se0：0.50 秒後に鳴らす、1 周（2.00 秒）ごとに鳴らし直す
  効果音 se1：1.50 秒後に鳴らす、2 周（4.00 秒）ごとに鳴らし直す
  ```
  効果音が「曲のトラック何番から鳴らすか」を確かめてください（6 章の決まりに合っているか）。
- 出力先（既定 `x68\anim\demo\`）に、`fm.zmd`（曲）、`se0.zse`・`se1.zse`（効果音）、`se0v.zmv`・`se1v.zmv`（効果音の音色）ができ、.pan の中に入ります。

項目：

| 項目（全体） | 意味                                                                                                                         | 既定 |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- | ---- |
| `fm`         | 曲のファイル（MML か ZMD）                                                                                                   | なし |
| `fm_offset`  | 曲を鳴らし始める時刻 [秒]（アニメの始まりから。0 以上）                                                                      | 0    |
| `fm_every`   | 永久ループで何周ごとに、曲を止めて頭から鳴らし直すか。0＝最初に 1 回だけ（`[do]`〜`[loop]` でくり返す曲なら 0 のままでよい） | 0    |

| 項目（`[[se]]`。効果音ごと、9 個まで） | 意味                                                                                             | 既定                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| `src`                                  | 効果音のファイル（MML か ZMD）                                                                   | 必須                                                   |
| `offset`                               | 鳴らす時刻 [秒]。永久ループでないときはアニメの始まりから、永久ループでは各周の頭から            | 0                                                      |
| `every`                                | 永久ループで何周ごとに鳴らすか。0＝最初に 1 回だけ。永久ループでないときは使わない（1 回鳴らす） | 1                                                      |
| `track`                                | 割り込ませる曲のトラック（1〜32）                                                                | 効果音の最初のトラックのチャンネルの番号（FM8 なら 8） |

- 時刻の考え方は ADPCM の `audio_offset` と `audio_every` と同じです。永久ループでは周を数えて、決めた周にだけ鳴らします。
  `offset` が 1 周より長いときは、その周から数え始めます（例：1 周 2 秒で `offset = 3.0` なら、2 周目の 1 秒目が最初）。
- 効果音の音色は、画面を出す前（準備の間）に Z-MUSIC に登録します。
- 終わるとき（キーで終える、最後まで再生する）に、FM 音源も止めます。
  ESC で止めたときも、FM 音源は止まります。もし鳴り続けたら `zmusic\zp -s` で止められます。
- ADPCM の音（`audio`）と同時に鳴らせます。

## 6. 曲と効果音の決まり

ツールが作るデータは次の 3 つです。

- **曲**（`.zmd`）：MML をコンパイルした ZMD そのものです。鳴らすと頭から鳴り、曲の中に `[do]`〜`[loop]` があれば、ずっとくり返します。
  鳴らし直すときは、鳴っている曲を止めてから頭から鳴らします。
- **効果音**（`.zse`）：ZMD から頭の部分と共通コマンドを外したものです。曲の演奏中のトラックに割り込んで鳴り、
  鳴り終わると、そのトラックは曲の続きに戻ります。
- **音色の表**（`.zmv`）：効果音の MML に音色の定義（`(v…)`）があるときに作ります。最初に 1 回、Z-MUSIC に登録します。

効果音の決まり（Z-MUSIC の決まり。ZM14.MAN の 14.1.5）：

- 共通コマンドは、音色の定義（`(v…)`、`(@…)`）のほかは使えません。トラックの確保と割り当て（`(m…)`、`(a…)`）、`(i)` は使えます。
  テンポは書きません（効果音は曲のテンポで鳴ります。MML の `T` を書くと、曲のテンポも変わります）。
- トラックは 8 本まで。音量・音色などの初期値は無いので、各トラックの頭で必ず書きます。`[ ]` の命令（`[do]`〜`[loop]` は使える）と和音は使えません。
- 効果音が鳴るチャンネルは、効果音の MML の `(a チャンネル,トラック)` で決まります。
  **割り込ませる曲のトラックは、効果音と同じチャンネルを鳴らしているトラック（または空いているトラック）にします。**
  - 例 1（チャンネルを空けておく）：曲は FM1〜FM7 だけを使い、効果音は FM8。曲で使っていないトラック 8 に割り込ませる（`track = 8`、既定のまま）。曲は欠けずに鳴ります。
  - 例 2（曲の 1 声を借りる）：曲が `(a8,8)` で FM8 をトラック 8 に割り当てて使っていて、効果音も FM8。トラック 8 に割り込ませると、効果音の間だけ曲の FM8 の声が休みます。
  - 違うチャンネルのトラックに割り込ませると、曲と効果音の両方がおかしくなります。
- 効果音の音色の番号は、曲の音色の番号と重ねないようにします（例：曲は 1 番から、効果音は 100 番から）。

そのほか：

- Z-MUSIC の ADPCM は使わないでください。panic の ADPCM（PCMP）と同じ ADPCM 音源を使うためです。曲と効果音は FM 音源で書きます。
- 曲のデータに MIDI のトラックがあっても、MIDI の機器が無ければ、その分は鳴りません。

## 7. mml2zmd：MML だけを変換する

mkanim・mkscene・mkparts は中でこれを使うので、ふつうは直接使う必要はありません。MML の間違いを先に確かめたいときや、手で書く .s に使うときに使います。

```
pt mml2zmd bgm.zms                    → bgm.zmd（曲）
pt mml2zmd shot.zms bomb.zms --se     → shot.zse、bomb.zse（効果音）。音色の定義があれば shotv.zmv なども
pt mml2zmd bgm.zms --out x68\anim\demo
```

- 出力先を省略すると、MML と同じフォルダに書きます。
- MML の間違いは「ファイル 行目：内容」で表示します。エラーの番号の意味は `docs/zmusic/ZM11.MAN` にあります。

## 8. 手で書く .s（mkparts とマクロ）

mkparts に MML を渡すと、曲（`.zmd`）を作り、ひな形の .s に鳴らす命令を入れます。効果音にする MML は `--se` で選びます。

```
pt mkparts title.png samples\fm\bgm.zms samples\fm\se.zms --se se.zms --name demo
```

.s では、次の命令（マクロ）を使います。`.include sch.h` の次に `.include zmusic.h`、`EXIT` の後に `.include zmusic.s` を置きます
（mkparts のひな形には入っています。くわしくは [LIBRARY.md](../LIBRARY.md) の 5 章）。

| 命令                   | 意味                                                   |
| ---------------------- | ------------------------------------------------------ |
| `ZMPL 曲`              | 曲を頭から鳴らす（鳴っている曲は止めてから）           |
| `ZMST`                 | 曲を止める                                             |
| `ZMFO 速さ`            | 曲をフェードアウトする（1〜85。大きいほど速い）        |
| `ZSEP 効果音,トラック` | 効果音を、曲のそのトラックに割り込ませて鳴らす         |
| `ZSES 効果音,トラック` | 効果音を途中で止める（曲のそのトラックは続きから鳴る） |
| `ZMVS 音色の表`        | 音色を登録する（効果音を鳴らす前に 1 回）              |

曲・効果音・音色の表は、素材のラベル（mkparts では `zm_<名前>`・`se_<名前>`・`sv_<名前>`）で書きます。

## 9. 時間について

- Z-MUSIC の命令にかかる時間（10MHz、エミュレータで測った値）：

  | 命令       | `zmsc -n` で常駐      | ふつうに常駐 |
  | ---------- | --------------------- | ------------ |
  | ZMPL       | 約 1ms                | 約 118ms     |
  | ZMST       | 約 25ms               | 約 25ms      |
  | ZSEP・ZSES | 約 0.3ms              | 約 0.3ms     |
  | ZMVS       | 約 0.2ms（音色 1 つ） | 約 0.2ms     |

  描画の見積もりと pansim は `zmsc -n` の値で数えます（ZMFO は仮の値）。ZMST は終わるときにだけ使います。
- 曲を頭（`fm_offset = 0`）で 1 回だけ鳴らすときは、ZMPL を画面を出す前に置きます。`-n` を付けずに常駐させたときも、アニメに影響しません。
  途中で鳴らす（`fm_offset` が 0 より大きい、`fm_every` を使う）ときは、`-n` を付けないと、その所で約 0.12 秒描けず、後のコマが飛ぶことがあります。
- 曲の演奏そのもの（Z-MUSIC の割り込み）も CPU の時間を使います。描画がぎりぎりのデータでは、FM 音源を鳴らすと処理落ちすることがあります。
  そのときは、描く量を減らすか、待ちを長くしてください。

## 10. うまくいかないとき

| こんなとき                              | 確かめること                                                                                                           |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 「MML のコンパイルに失敗しました」      | 表示された行の MML。エラーの番号の意味は `docs/zmusic/ZM11.MAN`。ファイルの拡張子が `.zms`／`.opm` か                  |
| 「ZMUSIC.X が見つかりません」           | `setup.bat` を実行する（`x68\zmusic\` に置かれる）                                                                     |
| 「FM 音源の曲（fm）が見つかりません」   | パスがどこからの相対か（mkanim のコマンドは実行しているフォルダ、設定ファイルは設定ファイルのあるフォルダ）            |
| 「効果音の MML に使えない共通コマンド」 | 効果音の MML から、テンポ（`(o…)`）などの共通コマンドを消す。テンポは書かない（6 章）                                  |
| 絵は出るが FM の音がまったく出ない      | panic の前に `zmusic\zmsc -n -t0 -w0` で常駐させたか。音色の定義（`(v…)`）があるか。`@` の音色番号が定義した番号か     |
| 曲は鳴るが効果音が鳴らない              | 効果音の MML の `(a チャンネル,…)` と、割り込ませる `track`（6 章）。効果音の MML に音量（`v`）・音色（`@`）を書いたか |
| 効果音が鳴ると曲がおかしくなる          | 割り込ませるトラックのチャンネルが、効果音のチャンネルと違っていないか（6 章）                                         |
| ときどき絵が止まる・コマが飛ぶ          | 常駐に `-n` を付けたか（2 章）。途中で曲を鳴らし直していないか（9 章）                                                 |
| アニメが終わっても曲が鳴っている        | ESC で止めたときに鳴り続けたら `zmusic\zp -s`                                                                          |
